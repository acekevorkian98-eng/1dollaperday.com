MakeYouTask Got a Makeover — Here's What Changed in 2026

News · 6 min read

Disclosure

This article contains referral links. If you sign up through our links, we may earn a small commission at no extra cost to you. This supports the site. See our full disclaimer.

MakeYouTask has had a full platform overhaul. The interface is new, the structure has changed, and the biggest thing you need to know: video earning is now mobile-only. If you were running videos on desktop, that no longer works. Desktop access still functions for other features. A new automation macro for the updated platform is in progress.

MakeYouTask has been on my stack for a while. It's paid consistently, the developer has been active, and the automation macros we've published here have worked well. So when the platform quietly rolled out a complete overhaul, it was worth a proper look rather than a one-line mention in a changelog.

The short version: the platform looks different, works differently in some important ways, and has made one change that directly affects how you earn from it. That change is the mobile-only video restriction, and if you were running a desktop setup, it matters.

This post covers what's changed, what it means for your earnings, and what still works on desktop while you figure out a new mobile setup.

The UI/UX Overhaul: What's Actually Different

The old interface was functional but clunky in places. Navigation took some getting used to, and the dashboard layout wasn't particularly intuitive for new users. The new version is a meaningful step up.

The redesign is cleaner and more organised. The main earning sections are easier to find. The dashboard gives you a better at-a-glance view of your balance and available tasks. Load times feel snappier.

A few things that are noticeably different:

  • The navigation structure has been reorganised — sections that were buried are now front and centre
  • The task/earning category labels have been updated
  • The overall visual design is more polished, less like a late-2010s GPT site
  • Mobile layout has clearly been prioritised — which makes sense given the direction the platform is going

Still Clunky in Places

The redesign is a genuine improvement, but it's not without rough edges. Some flows feel like they haven't been fully smoothed out yet. Expect minor quirks as the platform continues iterating. The developer has a track record of fixing things, so this is more "early post-launch friction" than a red flag.

The Big Change: Videos Are Now Mobile-Only

This is the change that actually matters for how you run MakeYouTask day-to-day.

Video earning — the MicroEarn/Watch & Earn section — now only works on mobile devices. Desktop browsers no longer load or credit video watching.

If you had a desktop tab running videos in the background, that tab is now earning you nothing. The platform detects whether you're on mobile, and if you're not, video tasks simply don't function.

This is a significant shift. One of the main reasons MakeYouTask earned its place in my stack was the ability to run it passively on desktop — background tab, videos rolling, earning while I worked on other things. That setup is gone.

Desktop Video Earning: Confirmed Dead

This is not a bug. The mobile-only restriction on video earning is intentional. Attempting to use desktop user-agent spoofing may work temporarily but risks account flags. The correct move is to shift video earning to an actual mobile device.

Why the Mobile-Only Change?

The platform hasn't made an explicit statement about the rationale, but the logic isn't hard to read. Mobile-only video earning is a stronger signal to advertisers that real humans are watching — it's harder to fake on mobile than on a desktop browser with a macro running. It also pushes the platform toward a mobile-first positioning, which is where the broader GPT/watch-to-earn space is heading anyway.

From an advertiser trust standpoint, it makes sense. From an earner's standpoint, it's an inconvenience that requires adjusting your setup.

What This Means for Your Earnings

The practical impact depends entirely on how you were using MakeYouTask before.

Your Previous Setup Impact What to Do
Desktop background tab for video earning No longer earns anything from video Move to a spare Android device or phone
Desktop automation macro (V1, V2, V3) Video automation scripts no longer function New mobile macro in progress — see below
Mobile device already in use Minimal impact — video earning still works May need to navigate the new UI layout
Desktop-only for PTC, offerwalls, faucet No impact — these still work on desktop Nothing to change

The headline: if video earning was part of your MakeYouTask routine and you were doing it on desktop, you need a mobile device in the picture now. A cheap spare Android phone or tablet on Wi-Fi is the standard solution in this category — something that can run the MakeYouTask app or mobile browser while you're not actively using it.

What Still Works on Desktop

The mobile-only restriction is video-specific. Desktop access to MakeYouTask isn't gone — it's just limited in what it can do for earning.

What still functions on desktop:

  • PTC ads — still clickable and credited on desktop
  • Offerwalls — survey and offer completion still works on desktop
  • Faucet claims — the 20-minute faucet still functions on desktop
  • Account management — balance, referrals, withdrawals all accessible
  • Withdrawals — no change here, FaucetPay payouts still process normally
  • Referral marketplace — buying and managing referrals still works on desktop

So desktop isn't useless. If your MakeYouTask routine was mostly PTC and offerwalls with video as a secondary earner, you'll barely notice the difference. If video was your primary earning method, mobile is now required for that part of the stack.

Split Your Setup

The practical approach: use desktop for PTC, faucet claims, offerwalls, and account management. Use mobile (phone or spare tablet) for video earning. This isn't dramatically different from how a lot of earners already run multi-device stacks for platforms like StreamPayz or RewardVid.

The New Macro: Coming Soon

Our existing MakeYouTask automation scripts — V1 through V3 — were desktop browser userscripts (Tampermonkey). With video earning moving to mobile, those scripts no longer apply to the video earning section.

A new macro is in development. The target platform is Android, using MacroDroid to automate the mobile video earning flow. The goal is the same as the desktop macros: semi-passive operation with minimal manual intervention.

What the new macro will need to handle:

  • Navigating the new mobile UI to the video earning section
  • Auto-starting video playback
  • Handling the between-video transitions and any confirmation taps
  • Looping across a session without manual input

No ETA Yet

The new macro requires testing on the updated mobile UI to get right. We won't publish something that half-works. When it's ready, it'll be posted here and linked from this article. If you're subscribed to the Telegram channel, the developer's announcements there will also flag any platform-side changes that affect macro behaviour.

Until then, manual mobile use is the play for video earning. It's more hands-on than the old desktop setup, but the earning rate hasn't changed — just the device it needs to run on.

Is MakeYouTask Still Worth It?

Yes, with the caveat that "it depends on your setup" is more true now than it was before.

The platform still pays. The developer is still active. The payout infrastructure hasn't changed. The referral marketplace — the feature that makes MakeYouTask actually interesting as a long-term earner — is still there and still functional on desktop. FaucetPay withdrawals still work.

The mobile-only video change is a real inconvenience for anyone who was running it on desktop. If you have a spare Android device gathering dust, this is a good reason to put it to work. If you're strictly desktop-only and video was a meaningful chunk of your MakeYouTask earnings, the platform is less useful to you until the mobile macro is out.

The overhaul itself — setting aside the mobile restriction — is a net positive. A cleaner UI and continued active development are good signs for platform longevity. This is still a platform that's being built, not one that's coasting.

Bottom Line

Keep MakeYouTask in your stack if it's already there. Shift video earning to mobile — spare Android device on Wi-Fi is the standard setup. Desktop still handles PTC, faucet, offerwalls, and referral management. New mobile macro coming. The platform hasn't gotten worse; it's just different.
